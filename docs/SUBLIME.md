# Sublime Text guide

Tines provides generated `Tines Light.sublime-color-scheme` and
`Tines Dark.sublime-color-scheme` files. They cover baseline syntax scopes,
markup, selections, search, guides, diagnostics, and both gutter and content
diffs.

## Install

In Sublime Text, open **Preferences → Browse Packages…**, enter the `User`
directory, and copy both files from this repository's `sublime/` directory.
Choose **Preferences → Select Color Scheme…**, then select **Tines Light** or
**Tines Dark**.

A Sublime color scheme controls the editor surface and syntax. Tabs, sidebars,
buttons, and other application chrome are controlled by Sublime's separate UI
theme, so Tines deliberately does not claim to recolor those components.

## Remove

Select another color scheme, then delete the two Tines files from the `User`
package directory.
