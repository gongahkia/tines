# Visual acceptance

Visual acceptance for Tines targets compares generated assets against canonical palette expectations in `palette/palette.json`.

The canonical showcase captures in `output/playwright/` were refreshed for the
Tines rename in both modes. Their capture environment, dimensions, and checksums
are recorded in [`support/visual-evidence.json`](../support/visual-evidence.json).
Native application references in `asset/reference/` predate the rename and
retain their original window titles; the approved colours are unchanged.
