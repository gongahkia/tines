# Tines for VS Code and Cursor

This extension supplies the generated `tines-light` and `tines-dark` themes. Both
derive from Tines's canonical palette; Cursor uses the same VS Code-compatible
extension without a separate theme copy.

See the repository's [VS Code and Cursor guide](https://github.com/gongahkia/tines/blob/main/docs/VSCODE.md)
for local development, VSIX packaging, installation, and removal instructions.
